Public presence

Check public links use our permanent links

Write-up is /autoscroll/. GitHub hop: /autoscroll/source/. Store hop: /autoscroll/store/.

These links can keep working if the destination changes. A hop is a redirect, not the public page itself.

Check the credit says who made it

In-app footer, popup, or README — link to https://dannyhope.co.uk (never dannyhope.com).

Check whether the GitHub repository is private

GitHub repo Settings, or gh repo view --json isPrivate,url,visibility. A folder name containing (private) is a strong private signal.

If it is private, leave it private unless Danny has asked you to make it public.

Check the README explains the project

Open this repository’s README. The first thing readers should see is what Autoscroll is for.
