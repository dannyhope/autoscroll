# Cross-browser test matrix

Repeatable manual real-browser protocol and evidence for the browser packages.
This document distinguishes package/static checks from real-browser runs: a
static check is not a pass for a browser behaviour row.

## Test protocol

For each browser:

1. Record the browser, macOS, package version, and package SHA-256.
2. Use a clean browser profile or remove the previous development install.
3. Install the package using the browser-specific development path.
4. Open a long ordinary HTML page with enough content to scroll for several
   seconds.
5. Run rows 1–6 in order, recording what was observed and any console or
   extension errors.
6. Reload the extension/package and repeat rows 1–6.
7. Repeat row 6 on a browser-restricted page and a non-HTML viewer where the
   browser provides one.

For rows 1–4, compare the page's scroll position at roughly one-second
intervals. For row 5, navigate away before the next interval and confirm the
new document remains still until the toolbar control is clicked.

| ID | Scenario | Expected result |
|---|---|---|
| 1 | Click toolbar icon on a long HTML page | Scrolling starts, moving about 1000px every 100ms |
| 2 | Click toolbar icon again | Scrolling stops |
| 3 | Scroll upward while running | Scrolling stops |
| 4 | Scroll downward while running | Scrolling continues |
| 5 | Navigate to another page while running | New page is not scrolling until clicked |
| 6 | Click on a restricted or unsupported page | No crash; the action is rejected safely and the page is unchanged |

## Regressions and platform limitations

- There is currently no Firefox or Safari behavioural evidence, so full
  cross-browser parity is not demonstrated.
- Safari development installation depends on an Xcode project, local signing
  configuration, Safari website-access permission, and the target Safari
  version. The current source scaffold alone is not installable.
- Restricted pages and non-HTML viewers may reject injection; each browser must
  be tested separately once its package is installable.
- Navigation reset is expected from a fresh document, but remains an explicit
  manual test rather than an assumption.
